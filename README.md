# Voice Typer

Free Chrome extension: click any text field, press the mic, speak in Arabic or English, and your words are typed.

- Draggable control box (mic, AR/EN switch, auto-correct toggle). Position is remembered; double-click the grip to reset.
- Alt+L switches language.
- Optional auto-correct (grammar/punctuation) via the free LanguageTool API. Spoken text is sent to languagetool.org while it is on. Free limit: 20 requests/minute.
- Speech recognition uses Chrome's built-in Web Speech API (needs internet).

## Install
1. Download or clone this repo.
2. Open `chrome://extensions` and enable Developer mode.
3. Click "Load unpacked" and select this folder.
